# 个人操盘工作台 · Personal Ops Workbench

> **一个人的短视频业务操作系统**
> 从灵感、选题、内容生产，到客户、项目、回款、复盘，全部在一个页面里完成。

你不是缺一个任务管理工具，你缺的是一套「个人业务操作系统」——
把 **灵感 → 素材 → 选题 → 内容生产 → 发布 → 数据 → 复盘 → 客户 → 成交 → 交付 → 回款** 串成完整闭环。

单文件 HTML，零依赖、零安装、离线可用。手机电脑都能用。

---

## ✨ 它解决什么问题

| 痛点 | 这个工作台怎么解决 |
|---|---|
| 一个人身兼数职，事情多且乱 | 首页「今日作战」按 **紧急程度 × 截止时间 × 业务价值** 自动排序，打开就知道现在最该干什么 |
| 不知道业务健不健康 | 「业务健康度」四个进度环：内容生产 / 客户项目 / 客户跟进 / 回款，一眼判断 |
| 不知道内容卡在哪 | 「内容生产漏斗」：灵感 → 脚本 → 拍摄 → 剪辑 → 已发布，卡在哪一眼看到 |
| 不知道钱在哪 | 「本月经营台账」：本月成交 / 已收 / 待收 / 待回款客户 / 已交付未结算，自动计算 |
| 灵感转瞬即逝 | 「随手记录」：打开 → 输入 → 保存，自动归档到任务 / 选题 / 素材库，不用填表 |
| 素材散落各处 | 「素材库」13 种素材类型 + 标签搜索筛选，长期沉淀为内容资产 |
| 账号多，谁没更新记不清 | 「账号驾驶舱」：自动诊断"已 7 天没发""计划发布日已过""储备为 0" |
| 客户跟进靠脑子记 | 「客户 CRM」12 阶段转化漏斗 + 跟进提醒 + 客户档案（痛点 / 心理 / 原话 / 商业价值） |
| 项目执行没有全局 | 「项目作战空间」：进度自动统计 + 时间线 + 项目财务 + 项目复盘，一个项目一个空间 |
| 复盘只看播放量 | 「内容情报中心」：互动率 + 规律分析 + **一键生成二次选题**，复盘结果直接变成新选题 |

## 🗺️ 两条业务闭环

```
【内容生产闭环】
灵感 → 素材 → 选题 → 脚本 → 拍摄 → 剪辑 → 发布 → 数据 → 复盘 → 新的选题

【商业闭环】
线索 → 客户 → 成交 → 项目 → 交付 → 回款 → 复购
```

模块之间自动联动：客户档案 → 一键建项目；账号作战室 → 一键加选题；
发布复盘 → 一键生成二次选题；项目交付 → 自动催回款。

## 🚀 快速开始（30 秒上手）

### 方式一：零安装，浏览器直接打开（推荐先试这个）

1. 下载本仓库的 [`workspace.html`](workspace.html)
2. 双击用浏览器打开（Chrome / Edge 均可）
3. 完了。页面会自动预置示例数据（带【示例】标记），点右上角「清空示例」即可从零开始

- 数据自动保存在**你自己电脑的浏览器**里（localStorage），不上传任何服务器
- 建议定期点右上角「导出备份」保存一份 JSON

### 方式二：WorkBuddy 内一键搭建（在线存储 + 多端同步）

在 WorkBuddy（或任何支持"资料库/数据表"能力的 AI 助手）里，把
[`prompts/workbuddy-install-prompt.md`](prompts/workbuddy-install-prompt.md) 的内容发给 AI，
AI 会自动帮你：建 8 张数据表 → 生成工作台页面 → 部署成在线链接。
手机、电脑、任何设备打开同一链接，数据自动同步。

### 方式三：让 Codex / Claude Code 等本地 AI 帮你部署

把 [`prompts/any-ai-prompt.md`](prompts/any-ai-prompt.md) 发给你的 AI，它会帮你完成本地部署。

### 方式四：豆包 / Manus 等云端 AI

同样使用 [`prompts/any-ai-prompt.md`](prompts/any-ai-prompt.md)，
让 AI 按这个产品规格重新生成或扩展你的专属版本。

> 📖 各方式的详细步骤、手机"添加到主屏幕"、数据备份与迁移方法，见 **[INSTALL.md](INSTALL.md)**

## 🧩 功能模块

### 首页 · 业务驾驶舱
- **今日作战**：🔴 现在必须处理 / 🟠 今天必须完成 / 🟡 有空再做，每条带一键处理按钮，逾期项自动置顶
- **业务健康度**：内容生产 / 客户项目 / 客户跟进 / 回款 四个进度环
- **内容生产漏斗 + 客户转化漏斗**：点任意一档，直接跳进对应模块并自动筛选
- **本月经营台账**：本月成交 / 已收 / 待收 / 待回款客户 / 已交付未结算
- **⚡ 随手记录**：一条输入框，AI 规则自动判断归档到 待办 / 选题 / 素材

### 八大模块
1. **今日任务** — 优先级 P0/P1/P2 + 截止日期 + 逾期红色提醒
2. **随手记录** — 灵感中转站，自动分类归档
3. **素材库** — 13 种素材类型 + 标签搜索，长期内容资产
4. **选题看板** — 灵感→脚本→拍摄→剪辑→已发布，状态下拉一键流转；每条选题自带**文案板**（大文本域，直接写/粘贴口播稿、分镜、字幕，Ctrl+Enter 保存）
5. **账号驾驶舱** — 自有/客户账号状态一目了然，自动诊断问题 + 本周建议
6. **客户 CRM** — 12 阶段转化流程 + 跟进提醒 + 客户档案 + 转化漏斗
7. **项目作战中心** — 项目空间（进度/时间线/财务/文件外链/复盘）+ 回款管理
8. **内容情报中心** — 互动率分析 + 规律总结 + 一键生成二次选题

## 🔒 数据与隐私

- **本地模式**：所有数据存在你自己的浏览器 localStorage，不经过任何服务器
- **平台模式**：数据存在平台的数据表中，受平台账号体系保护
- 部署到公网时，链接是可分享的，但**数据只在你自己的浏览器里**——别人打开链接看到的是他自己的空白数据
- 内置「导出备份 / 导入恢复」，数据永远可迁移
- 页面预置的示例数据均为虚构，可在右上角一键清空
