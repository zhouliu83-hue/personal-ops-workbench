# 通用 AI 搭建指令（Codex / Claude Code / 豆包 / Manus / 任意 AI）

> 使用方法：把下面分割线以内的**全部内容**复制粘贴给任意 AI。
> 适用于：本地编程 AI（Codex、Claude Code、Cursor 等）和云端 AI（豆包、Kimi、Manus 等）。
> 生成结果是单文件 HTML，保存后双击用浏览器打开即可使用，数据存在浏览器本地。

---

请为我生成一个「个人短视频操盘工作台」，并严格按以下规格执行。

## 产品定位
一个人的短视频业务操作系统。不是后台管理工具，而是"业务指挥中心"：
打开首页第一眼就知道——今天最该干什么、业务健不健康、内容卡在哪、还有多少钱没收。

## 硬性技术约束（必须全部满足）
1. **单文件 HTML**：所有 CSS/JS 内联，不引用任何外部框架、CDN、字体、图表库
2. **数据存储**：localStorage，key 前缀统一 `pow_`；提供「导出备份（JSON下载）」「导入恢复」「清空示例数据（二次确认）」
3. **图标**：内联 SVG path，严禁 emoji 当图标；**图表**：内联 SVG 手写（进度环、漏斗条）
4. **响应式**：手机窄屏单列堆叠，按钮≥44px，输入框字号≥16px，适配 `env(safe-area-inset-bottom)`
5. **代码架构**：函数调用链单向无环，渲染函数之间严禁互调，统一 `refreshAll()` 入口；数据层→计算层→渲染层分层
6. **首次打开**：预置示例数据（每模块 3 条左右，含 1 条逾期任务），全部带【示例】前缀，可一键清空
7. **配色**：白/浅灰底(#F4F5F7/#FFF) + 橙色 #E8562A 强调色，大字号数字，圆角卡片+细描边+分层阴影；不要大面积渐变、不要赛博朋克
8. **国内习惯**：货币 ¥，日期 YYYY-MM-DD 或 X月X日

## 数据模型（8 个模块，字段必须一致）

1. **今日任务**：任务内容、关联账号、优先级(P0紧急/P1重要/P2常规)、截止日期、状态(待办/进行中/已完成)、备注
2. **随手记录**：记录内容、分类(灵感/观点/素材/选题/待办/客户需求/案例)、归档状态(未处理/已归档)、记录日期
3. **素材库**：素材标题、素材内容、素材类型(观点/故事/案例/社会现象/客户原话/评论区金句/金句句子/影视素材/书籍素材/商业案例/个人经历/临时灵感/其他)、来源、标签(逗号分隔)、关联账号、关联选题、使用状态(未使用/使用中/已使用)、备注；支持搜索和按类型筛选
4. **选题看板**：选题标题、发布平台(多选：抖音/视频号/小红书/快手)、所属账号、进度状态(灵感/脚本中/拍摄中/剪辑中/已发布)、预计发布日期、备注
5. **账号驾驶舱**：账号名称、平台(抖音/视频号/小红书/快手/其他)、账号类型(自有账号/客户账号)、所属客户、账号定位、内容方向、更新频率、最近发布时间、下次计划发布时间、当前待发布数量、本周发布数量、账号状态(正常/待更新/暂停/运营中)、备注
6. **客户CRM**：客户名称、联系方式、行业、城市、客户类型(个人IP/实体商家/其他)、客户核心问题、客户想要的结果、客户心理、客户预算、客户来源、合作阶段(陌生线索→已添加→已沟通→需求确认→报价→洽谈中→已成交→执行中→已交付→已结算→复购→暂停流失)、最近沟通时间、下次跟进时间、沟通记录、客户原话、累计成交金额、备注
7. **项目台账**：项目名称、客户、项目类型(账号代运营/单条拍摄/账号策划方案/线上陪跑/其他)、合同金额、已收金额、项目成本、成交日期、项目状态(洽谈中/已签约/执行中/已交付/已结算)、交付截止、思维导图链接、定位表链接、成交原因、执行问题、客户最满意、可标准化环节、是否值得复购(值得/不值得/待评估)、备注
8. **内容数据复盘**：内容标题、所属账号、平台、发布时间、核心观点、开头方式、冲突点、播放量、点赞数、评论数、收藏数、转发数、涨粉数、私信数、获客数量、成交数量、高频评论、我的发现、下次怎么做

跨表关联用名称软关联：客户名 ↔ 项目的"客户"字段、账号的"所属客户"字段；账号名 ↔ 选题/复盘的"所属账号"。

## 首页「业务驾驶舱」（最重要，按此顺序）
1. 轻量问候卡：按时段问候 + 日期；右侧今日状态格（今日待办/待发布/待跟进/临近交付/待回款¥），点击跳转对应模块
2. **⚡ 随手记录**：一个大输入框 + 保存按钮，按关键词规则自动归档——含"提醒/明天/记得"→任务表(待办)；含"选题/拍一条/写一期"→选题看板(灵感)；其余→素材库(临时灵感)；保存后 toast 告知归到哪了
3. **💰 本月经营台账**：本月成交/本月已收/本月待收/待回款客户数/已交付未结算数（合同金额−已收金额=待收，自动算）
4. **🎯 今日作战**：按 紧急程度×截止时间×业务价值 排序分三层：🔴现在必须处理(逾期)/🟠今天必须完成/🟡有空再做；每条含标题、逾期天数/截止日、下一步动作按钮（完成任务/顺延今天/记为已跟进/标记已交付/去剪辑）
5. **业务健康度**：4 个 SVG 进度环——内容生产(本周已发布/计划)、客户项目(未逾期项目占比)、客户跟进(已按期跟进占比)、回款(已收/合同)
6. **内容生产漏斗**（灵感→脚本→拍摄→剪辑→已发布 数量条）+ **客户转化漏斗**（新线索→已沟通→报价洽谈→已成交→执行中→已交付→复购）；点任意一档跳到模块并自动筛选
7. **＋新建**按钮：弹出菜单可新建 任务/选题/素材/客户/项目/复盘
8. 最近灵感、最近发布内容、TOP 内容（按播放量）

## 模块页要求
- 列表用卡片，不用表格；每条含状态下拉（改了立即生效）、编辑、删除
- 卡片按状态/日期自动排序，逾期/临期标红
- **账号驾驶舱**：卡片含状态灯+待发布数+最近发布距今天数；自动诊断文案（"已N天没发""计划发布日已过""内容储备为0"）；详情页含本周建议
- **客户CRM**：漏斗点选筛选；详情档案聚合：痛点/想要结果/心理/原话/商业价值（项目数、累计金额、复购判定）/关联项目与账号；一键"为TA建项目"
- **项目作战中心**：项目卡含金额大数字+进度条(按该项目选题状态统计)+交付风险预警；点"进入项目空间"弹窗：执行进度(各阶段选题数)、项目时间线(成交→任务→发布自动排)、项目财务(合同/已收/待收/利润，一键"收到回款")、项目文件(思维导图链接→新窗口打开XMind、定位表链接→WPS)、项目复盘(成交原因/执行问题/客户最满意/可标准化环节/是否值得复购)
- **内容情报中心**：自动算互动率(点赞率/评论率/收藏率=对应数÷播放量)；规则分析（"评论率高，观点有争议，适合二次创作""收藏高是有用型内容"等）；一键"生成二次选题"：把"我的发现+下次怎么做"变成新选题写入看板

2. 生成后自检：JS 无语法错误、所有 getElementById 的元素存在、空数据不崩、函数调用无环
3. 告诉我：怎么打开使用、怎么备份数据、怎么清空示例数据
