# WorkBuddy 一键搭建指令

> 使用方法：在 WorkBuddy 对话框中，把下面分割线以内的**全部内容**复制粘贴发送即可。
> AI 会自动建表、生成页面、部署上线，交付一个多设备同步的在线链接。
> 如果你想先改名（比如把「周正工作台」换成你的名字），直接改文字再发送。

---

请帮我搭建一个「个人短视频操盘工作台」，定位是**一个人的短视频业务操作系统**，要按以下完整规格执行：

## 一、先创建 8 张数据表（字段名必须完全一致）

**1. 任务清单**：任务内容(文本)、关联账号(文本)、优先级(单选：P0 紧急/P1 重要/P2 常规)、截止日期(日期)、状态(单选：待办/进行中/已完成)、备注(文本)

**2. 随手记录**：记录内容(文本)、分类(单选：灵感/观点/素材/选题/待办/客户需求/案例)、归档状态(单选：未处理/已归档)、记录日期(日期)

**3. 素材库**：素材标题(文本)、素材内容(文本)、素材类型(单选：观点/故事/案例/社会现象/客户原话/评论区金句/金句/句子/影视素材/书籍素材/商业案例/个人经历/临时灵感/其他)、来源(文本)、标签(文本，逗号分隔)、关联账号(文本)、关联选题(文本)、使用状态(单选：未使用/使用中/已使用)、备注(文本)

**4. 选题看板**：选题标题(文本)、发布平台(多选：抖音/视频号/小红书/快手)、所属账号(文本)、进度状态(单选：灵感/脚本中/拍摄中/剪辑中/已发布)、预计发布日期(日期)、文案(长文本，选题的文案板)、备注(文本)

**5. 账号驾驶舱**：账号名称(文本)、平台(单选：抖音/视频号/小红书/快手/其他)、账号类型(单选：自有账号/客户账号)、所属客户(文本)、账号定位(文本)、内容方向(文本)、更新频率(文本)、最近发布时间(日期)、下次计划发布时间(日期)、当前待发布数量(数字)、本周发布数量(数字)、账号状态(单选：正常/待更新/暂停/运营中)、备注(文本)

**6. 客户CRM**：客户名称(文本)、联系方式(文本)、行业(文本)、城市(文本)、客户类型(单选：个人IP/实体商家/其他)、客户核心问题(文本)、客户想要的结果(文本)、客户心理(文本)、客户预算(文本)、客户来源(文本)、合作阶段(单选：陌生线索/已添加/已沟通/需求确认/报价/洽谈中/已成交/执行中/已交付/已结算/复购/暂停流失)、最近沟通时间(日期)、下次跟进时间(日期)、沟通记录(文本)、客户原话(文本)、累计成交金额(货币)、备注(文本)

**7. 项目台账**：项目名称(文本)、客户(文本)、项目类型(单选：账号代运营/单条拍摄/账号策划方案/线上陪跑/其他)、合同金额(货币)、已收金额(货币)、项目成本(货币)、成交日期(日期)、项目状态(单选：洽谈中/已签约/执行中/已交付/已结算)、交付截止(日期)、思维导图链接(文本)、定位表链接(文本)、成交原因(文本)、执行问题(文本)、客户最满意(文本)、可标准化环节(文本)、是否值得复购(单选：值得/不值得/待评估)、备注(文本)

**8. 内容数据复盘**：内容标题(文本)、所属账号(文本)、平台(单选：抖音/视频号/小红书/快手/其他)、发布时间(日期)、核心观点(文本)、开头方式(文本)、冲突点(文本)、播放量(数字)、点赞数(数字)、评论数(数字)、收藏数(数字)、转发数(数字)、涨粉数(数字)、私信数(数字)、获客数量(数字)、成交数量(数字)、高频评论(文本)、我的发现(文本)、下次怎么做(文本)

## 二、生成单文件工作台页面，要求如下

**技术硬约束**：
- 单文件 HTML，全部 CSS/JS 内联，不引用任何外部框架/CDN/字体/图表库
- 图标用内联 SVG，不用 emoji 当图标；图表用内联 SVG 手写
- 数据读写通过平台数据库 SDK，8 张表都要绑定；页面展示同步状态指示器
- 手机电脑自适应：窄屏单列、按钮≥44px、输入框字号≥16px、底部适配安全区
- 函数调用链必须是单向无环的：渲染函数之间严禁互调，统一用 refreshAll() 入口刷新

**首页「业务驾驶舱」（打开即开工）**：
1. 顶部轻量问候卡（时段问候+日期），右侧今日状态格：今日待办/待发布/待跟进/临近交付/待回款¥，可点击跳转
2. **⚡ 随手记录**输入框：打开→输入→保存，按关键词规则自动归档（含"提醒/明天/记得"→待办进任务表；含"选题/拍一条"→进选题看板；其余→素材库）
3. **💰 本月经营台账**（放最前面）：本月成交/已收/待收/待回款客户/已交付未结算，合同金额-已收金额=待收金额自动计算
4. **🎯 今日作战**：按 紧急程度×截止时间×业务价值 自动排序分三层——🔴现在必须处理(逾期)/🟠今天必须完成/🟡有空再做，每条带一键处理按钮（完成/顺延今天/记为已跟进/标记已交付）
5. **业务健康度**：内容生产/客户项目/客户跟进/回款 四个进度环
6. **内容生产漏斗 + 客户转化漏斗**：点任意一档跳到对应模块并自动筛选
7. **＋新建**全局菜单：任务/选题/素材/客户/项目/复盘
8. 最近灵感 / 最近发布内容 / TOP 内容

**八大模块页**（每个模块顶部一句"它解决什么"的 tagline）：
- 今日任务：状态/优先级下拉一键流转，逾期标红
- 随手记录：未处理/已归档
- 素材库：按素材类型筛选 + 全文搜索
- 选题看板：进度状态下拉流转，到期未发标红；点选题标题打开「文案板」：大文本域直接写/粘贴口播稿、分镜、字幕，Ctrl+Enter 保存，实时字数统计
- 账号驾驶舱：状态灯卡片，自动诊断（已7天没发/计划发布日已过/储备为0），详情页含本周建议、选题池、爆款内容
- 客户CRM：转化漏斗筛选，详情档案（痛点/想要结果/心理/原话/商业价值），一键"为TA建项目"预填客户名
- 项目作战中心：项目卡（金额大数字+自动进度条+交付风险预警），点进项目空间：执行进度（按该项目选题自动统计）、项目时间线、项目财务（合同/已收/待收/利润）、项目文件（思维导图链接跳XMind、定位表链接跳WPS）、项目复盘字段、一键"收到回款"
- 内容情报中心：互动率（点赞率/评论率/收藏率）自动计算 + 规律分析 + 一键"生成二次选题"进看板

**其他**：
- 右上角「导出备份」按钮（导出全部数据 JSON）、「清空示例」按钮
- 预置 3-5 条示例数据（含 1 条逾期任务、1 个久未更新的客户账号），全部带【示例】前缀标记
- 配色：白/浅灰底 + 橙色 #E8562A 强调色，大字号数字，卡片分层，避免后台管理系统的表格感
